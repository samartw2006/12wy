    Time Block Strategy

    📅 ช่วงเวลาของ 12-Week Year
    ระบบจะคำนวณวัน/สัปดาห์ทั้งหมดจากวันที่เริ่มต้น · เปลี่ยนได้แต่ข้อมูลที่กรอกไว้จะถูก map ตามวันที่เดิม
    ☁️ Cloud Sync (GitHub Gist)
    Sync ข้อมูลข้ามเครื่อง/เบราว์เซอร์ ผ่าน GitHub private gist · ฟรี · ตั้งค่าครั้งเดียว แล้ว auto-sync ทุกครั้งที่กรอก · ใช้ token เดียวได้ทุกเครื่อง
    ยังไม่ได้ตั้งค่า sync
    💾 Export ข้อมูล
    ดาวน์โหลดข้อมูลทั้งหมด (daily, weekly, milestones, config) เป็นไฟล์ JSON · เก็บไว้เป็น backup หรือย้ายไปอุปกรณ์อื่น
    📥 Import ข้อมูล
    นำข้อมูลจากไฟล์ backup กลับเข้ามา · ข้อมูลที่มีอยู่จะถูกแทนที่ด้วยข้อมูลใหม่ตาม key ที่ตรงกัน
    🔄 Reset milestones/habits/vision เป็นค่าเริ่มต้น
    คืนค่า config เริ่มต้นที่ออกแบบไว้ในตอนแรก (ไม่กระทบข้อมูล daily/weekly ที่กรอกไว้)
    ⚠️ Reset ข้อมูลทั้งหมด
    ลบข้อมูลทุกอย่าง — daily entries, weekly scorecards, milestone statuses, custom configs · ทำแล้วกู้ไม่ได้
    💾 พื้นที่จัดเก็บข้อมูล
    ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์บนเครื่องนี้ · ไม่ส่งออกไปไหน · แต่ละเบราว์เซอร์/แต่ละเครื่องจะมีข้อมูลแยกกัน · การล้างข้อมูลเบราว์เซอร์ (Clear browsing data) จะทำให้ข้อมูลหาย
    —
    ℹ️ About
    12-Week Year App · ทำงานแบบ offline ได้ · ไม่ต้อง login · ไม่มี server · แนะนำให้ Download backup เป็นระยะ (เผื่อเครื่องเสีย หรือเปลี่ยนเบราว์เซอร์)
