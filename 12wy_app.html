    Time Block Strategy (shared)

    📅 ระบบ Cycle (Continuous flow)
    ระบบใช้ 1 มกราคม 2569 (2026) เป็น Day 1 ของ Cycle 1 · 4 cycles × 84 วัน = 336 วัน/ปี · หลัง C4W12 จบ → C1W1 ของปีถัดไปเริ่มต่อทันที (ไม่มี leftover)
    ผลคือ "ปี" ของระบบจะค่อย ๆ เลื่อนเร็วกว่าปฏิทินจริงประมาณ 29-30 วัน/ปี · เช่น 2027 C1 เริ่ม 3 ธ.ค. 2569 (ก่อนปีใหม่จริง 29 วัน)
    แต่ละ cycle มี goals, milestones, weekly entries แยกของตัวเอง — ใช้ปุ่ม ◀ ▶ ในแต่ละ tab เพื่อสลับ cycle
    📋 OKR Template (1-year 2026)
    Apply โครงสร้าง 3 Goals + 22 milestones + tactics ที่ map กับ 1-year OKRs ของคุณ ลงใน cycle ที่กำลังดู (เปลี่ยน cycle ด้วยปุ่ม ◀ ▶ ในแท็บอื่นก่อนกด)
    Goals: G1 Learning · G2 Wellbeing · G3 Research
    Milestones: Cycle-portion checkpoints ทุก W4, W8, W12
    Habit ใหม่: ✍️ เขียน manuscript (60 นาที/วัน)
    ทำหลายครั้งได้ — milestones จะถูก append (ไม่ลบของเก่า) · goals จะถูกแทนที่
    ☁️ Cloud Sync (GitHub Gist)
    Sync ข้อมูลข้ามเครื่อง/เบราว์เซอร์ ผ่าน GitHub private gist · ฟรี · ตั้งค่าครั้งเดียว แล้ว auto-sync ทุกครั้งที่กรอก · ใช้ token เดียวได้ทุกเครื่อง
    ยังไม่ได้ตั้งค่า sync
    💾 Export ข้อมูล
    ดาวน์โหลดข้อมูลทั้งหมด (daily, weekly, cycles, configs) เป็นไฟล์ JSON · เก็บไว้เป็น backup หรือย้ายไปอุปกรณ์อื่น
    📥 Import ข้อมูล
    นำข้อมูลจากไฟล์ backup กลับเข้ามา · ข้อมูลที่มีอยู่จะถูกแทนที่ด้วยข้อมูลใหม่ตาม key ที่ตรงกัน
    🔄 Reset ค่าเริ่มต้น (shared configs)
    คืนค่า config ที่ใช้ร่วมทุก cycle · ไม่กระทบ cycles หรือ daily/weekly entries
    🧹 Clear Cycle ปัจจุบัน
    ลบ goals, milestones, weekly entries ของ cycle ที่กำลังดูอยู่ (ในแท็บ Weekly/Milestones/Dashboard) · daily entries และ shared configs จะคงอยู่
    ⚠️ Reset ข้อมูลทั้งหมด
    ลบข้อมูลทุกอย่าง — daily, weekly, cycles, configs, sync · ทำแล้วกู้ไม่ได้
    💾 พื้นที่จัดเก็บข้อมูล
    ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์บนเครื่องนี้ · ไม่ส่งออกไปไหน · แต่ละเบราว์เซอร์/แต่ละเครื่องจะมีข้อมูลแยกกัน
